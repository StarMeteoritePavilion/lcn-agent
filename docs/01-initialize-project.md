## 当前步骤目标

确认 Node.js 和 npm 可用，生成可以被 npm 读取的项目配置。

## 执行

在终端依次执行：

```bash
cd /Users/can/Projects/AI/lcn-agent
node --version
npm --version
npm init -y
```

命令含义：

| 命令 | 用途 |
| --- | --- |
| `cd` | 进入项目目录 |
| `node --version` | 查看 Node.js 运行时版本 |
| `npm --version` | 查看 npm 包管理工具版本 |
| `npm init -y` | 使用默认值初始化 npm 项目，生成 `package.json` |

`package.json` 是项目的配置入口，记录名称、版本、依赖和常用命令。
初始化不会安装 TypeScript，也不会生成业务代码。

先认识三个字段：

| 字段 | 用途 |
| --- | --- |
| `name` | 项目名称 |
| `version` | 项目版本 |
| `scripts` | 可通过 `npm run` 执行的命令 |

## 验证

```bash
npm pkg get name version scripts
```

通过标准：

- 两条版本命令均输出版本号，没有报错。
- 项目目录生成 `package.json`。
- npm 成功输出名称、版本和脚本配置。

默认 `test` 脚本只是占位提示，会提示尚未配置测试并以非零状态退出，本步不用执行。
